# Welcome to MD Convert!

Convert **Markdown** files to beautifully styled HTML, right on your phone.

## How to Use

1. Tap the **+** button to open a `.md` file
2. Or tap the **clipboard** button to paste markdown text
3. Use the **eye** button to toggle between rendered HTML and raw markdown
4. Tap the **copy** button to copy the HTML to your clipboard

You can also **share** markdown files or text from other apps directly to MD Convert.

## Supported Features
